# MCAC · Minecraft 外置助手

> 一个 JAR，不用改客户端，不用装前置 Mod。  
> 把 Java Agent 挂进游戏进程，连点器、瞄准、蹲搭、回溯都在外面跑 —— 游戏里只负责“被操作”。

## 这是什么

MCAC（Minecraft Auto Clicker & More）是一个**外置**的 Minecraft 助手：

- 不做 Mod，不碰 `mods` 文件夹，不需要 Forge/Fabric 前置；
- 通过 `Java Agent` 按 **PID** 附加到已经运行的游戏进程；
- 在游戏内用 ASM 注入极少量字节码，把玩家状态、实体列表通过一条本地 TCP 探针吐出来；
- 桌面端（Swing + FlatLaf）读数据、做决策，再用系统级输入把动作“打”回游戏。

一句话：**它不修改你的客户端，它只是坐在你旁边，替你按鼠标。**

## 能做什么

| 模块 | 干什么 | 实现要点 |
| --- | --- | --- |
| 左/右键连点器 | 按住触发键，按设定 CPS 连续点击 | CPS 区间 + 均匀/高斯/偏态曲线 + 定时与准星抖动 |
| 瞄准辅助 | 平滑把视角转向范围内最近的实体 | 角度误差 → 鼠标计数换算（含游戏内灵敏度），带锁定容差 |
| 鹰眼（蹲搭） | 走到方块边缘自动蹲下 | 脚下实地 + 运动方向前方 N 格悬空才触发 |
| 受击跳跃 | 被玩家打飞时补跳 | 只认“附近存在其他玩家”的受伤瞬间，忽略摔落与生物击退 |
| 自动疾跑 | 按住 W 自动疾跑 | 松开 W / 按住 Shift / 自己按着疾跑键时都不接管 |
| 回溯 Backtrack | 攻击时暂停处理入站包 | 结束后回放；支持最长 5000ms 与“持续缓慢释放” |

还有一些小心思：

- **只在世界里生效**、**只在手持方块或剑时生效**，两个开关可组合；
- 注入的按键不会被自己识别成“用户按键”（低级钩子过滤 `INJECTED` 标记）；
- 窗口标题被客户端改成服务器名也不影响判定，因为前台检测按 **进程 PID** 来；
- 动态端口 + `%TEMP%\mcac\bridge-<pid>.port`，多开也不会抢端口。

## 在线试玩

[`docs/index.html`](docs/index.html) 是一个**纯前端交互演示**，和桌面端共用同一套参数语义：

- 连点器：换 CPS 曲线、打开“手持过滤”，看它如何被空手拦住；
- 瞄准：目标在水平和垂直方向游走，还能一键复现“旧版 y 轴反号”的离谱手感；
- 鹰眼：拖动触发距离，看探测点提前多少格开始蹲；
- 回溯：按住攻击攒包，对比“一次性回放”和“30 包/秒缓慢释放”。

它不会注入任何东西，也不会点击任何东西 —— 只是把这套交互讲清楚。

开启在线地址：仓库 `Settings → Pages`，Source 选 `Deploy from a branch`，分支 `main`、目录 `/docs`，保存后访问
`https://<你的用户名>.github.io/<仓库名>/`。

## 快速开始

### 1. 构建

需要 JDK 8（Gradle toolchain 会锁定 Java 8），依赖已放在 `libs/`，可完全离线构建：

```bash
gradle dist --offline
```

产物：

- `agent/build/libs/mcac-agent.jar` —— 注入进游戏内的探针
- `client/build/libs/MCAC.jar` —— 桌面端（已内嵌 agent，单文件即可分发）

### 2. 运行

1. 启动 Minecraft，**进入世界**（主菜单没有玩家实例，探针会一直等）；
2. 双击 `MCAC.jar`（或 `java -jar MCAC.jar`）；
3. 点“注入游戏”，或在“其他”页填入游戏 PID 后按 PID 注入；
4. 状态变成 `世界中 · 实体 N · 正常` 后，各模块才开始接管。

> 游戏以管理员身份运行时，普通权限既不能附加也不能送输入，客户端会提示并通过 UAC 提权重启自己。

### 3. 更新后

重启游戏 → 重新注入。旧 JVM 里的 agent 类不能热替换，这是 Java 的规矩，不是 bug。

## 工作方式

```
┌──────────────┐   Attach / Agent    ┌─────────────────────────┐
│  MCAC 桌面端  │ ──────────────────▶ │ Minecraft JVM           │
│ Swing + JNA  │                     │  └ mcac-agent           │
│              │ ◀── TCP 探针 v5 ─── │      └ SensorBridge     │
│ 决策 + 输入   │                     │  (ASM 注入 tick/收包口)  │
└──────┬───────┘                     └─────────────────────────┘
       │ mouse_event / keybd_event
       ▼
    系统输入队列 ──▶ 游戏窗口
```

- **探针协议**（逐行文本）：`HELLO 5`、`S 0/1` 世界心跳、`F ...` 玩家与实体快照；
- 客户端命令：`B 1 <ms> <slow>` / `B 0` 控制回溯，`E <dist>` 设置鹰眼探测距离；
- “是否在世界里”不靠猜：以玩家 **tick 是否在推进** 为准，退出世界立刻失效。

## 版本支持

| 环境 | 状态 |
| --- | --- |
| 1.8.9 Forge（MCP 类名 + SRG 成员） | 支持 |
| 1.20.1 – 1.21.8（Fabric / NeoForge / 官方映射 / 原版） | 支持 |
| Java 8 / 17 / 21 目标进程 | 支持（ASM API 按运行时能力自适应） |

几个踩过的坑，已经写进代码：

- 1.8.9 Forge 自带 `asm-all-5.0.3`，注入用高版本 ASM 会直接炸 → 按运行时能力选 API；
- `BlockPos` 的三个 int 在父类里 → 跨继承链找字段；
- 1.21.5 之后 `SwordItem` 没了 → 手持判定退回翻译键（`item.*_sword` / `block.*`）。

## 常见问题

**注入成功但模块没反应？**  
先确认状态是“世界中”。再确认游戏窗口在前台 —— 所有模块都要求前台，否则就是后台挂机脚本了。

**连点器开了“仅在手持方块或剑时生效”却完全不点？**  
看状态栏的手持判定；空手或拿着食物/工具本来就会被拦住。

**回溯开了之后位置一直往回拽？**  
把最长回溯时间调小，或打开“持续缓慢释放”，让缓存按 30 包/秒补发而不是一口气倒出来。

**端口是多少？**  
不需要手填。客户端按 `%TEMP%\mcac\bridge-<pid>.port` 自动发现，多开互不影响。
