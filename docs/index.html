关于这份演示

纯前端模拟，用于说明参数与手感

页面不会读取你的游戏进程，也不会注入任何代码。真实程序通过 Java Agent 附加到 Minecraft， 按 PID 注入、动态端口通信，并在检测到玩家 tick 推进后才允许各模块生效。 源码、构建方式与 MIT 许可见仓库根目录 README。
